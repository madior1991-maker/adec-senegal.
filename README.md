# ADEC-Sénégal — site web

Refonte du site de l'Association pour la Défense de l'Environnement et des Consommateurs (ADEC-Sénégal).

- `index.html` : le site (pages Accueil, Actualités, Article, Centre de ressources, Contact), trois modèles de design au choix.
- `img/` : photos retouchées et logo.

Les actualités et les documents du centre de ressources sont stockés dans la base de données de l'aperçu Claude. Pour l'hébergement définitif, ils devront être branchés sur un outil d'administration (CMS).
